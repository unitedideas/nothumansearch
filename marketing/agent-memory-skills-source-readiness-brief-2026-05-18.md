## Owner-Channel Framing

Draft angle:

> Agents are not only looking for APIs. They are looking for reusable skills, memory servers, source-code loops, and tool contracts. If those projects only expose human docs, agent discovery becomes guesswork. Not Human Search checks whether the public surface is actually probeable: MCP, OpenAPI, structured API, llms.txt, plugin metadata, robots policy, and Schema.org.

Use cases:

- Agent memory/MCP server owners: make memory stores, skills, and tool contracts machine-readable.
- Agent framework/source-code projects: expose install, API, and capability boundaries in stable public metadata.
- High-score owners: add free monitoring and badge/report proof so regressions are caught.
- Partial-score owners: run `/score` first, then use score-fix only if the public score still has concrete gaps.
