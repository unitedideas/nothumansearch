What "agent-ready" means here

A site only enters the index if it exposes at least one hard agent signal — a structured API, an OpenAPI spec, an MCP server, or an ai-plugin manifest. Passive markup alone (an llms.txt with nothing behind it, Schema.org, robots rules) does not qualify a site. So the average above is the average among sites that already do something for agents — the broader web scores far lower.

How the score works

Each indexed site is scored 0–100 across 7 signals. Each signal is a distinct way a site supports programmatic access by an AI agent.

llms.txtMachine-readable site description at /llms.txt25
